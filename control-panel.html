How to use it

  1. Pick a recipe to load the three ingredient set-weights.
  2. Press START and the line fills silos, weighs each powder, mixes, sieves and collects.
  3. Hit E-STOP any time to trip a fault, then RESET to clear it.

This is a faithful behaviour simulation for demonstration. Real panels use Siemens / Allen Bradley / Mitsubishi / Schneider PLCs with recipe management, data logging and safety interlocks.
